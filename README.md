# ⚔️ Mercador Biruta — Loja de RPG

Um jogo web interativo de loja de RPG com sistema de negociação, combate e compras de itens!

## 🎮 Recursos

- **Loja Interativa**: Compre 10 itens diferentes com emojis incríveis
- **Sistema de Negociação**: Tente negociar preços com Biruta
- **Sistema de Combate**: Enfrente inimigos em combate para ganhar ouro
- **Animações Suaves**: Efeitos visuais e animações CSS 3D
- **Design Retro**: Tema inspirado em RPGs clássicos de 8-bit
- **Responsivo**: Funciona em desktop e dispositivos móveis

## 🚀 Como Começar

1. Abra `index.html` em seu navegador
2. Explore a loja e compre itens
3. Negocie com Biruta para conseguir descontos
4. Participe de combates para ganhar mais ouro

## 🎨 Tecnologias Utilizadas

## 🎯 Como Jogar

### Comprar Itens
1. Clique em um item para selecioná-lo
2. Clique novamente para comprar
3. Você precisa de ouro suficiente

### Negociar
1. Clique no botão "Negociar Preço"
2. Se bem-sucedido, todos os itens ganham 30% de desconto
3. Se falhar, Biruta o desafia para combate

### Combate
1. Escolha entre atacar ou se defender
2. Derrotar inimigos garante recompensa em ouro
3. Perder custa 100 ouro

## 💰 Economia do Jogo

- **Ouro Inicial**: 1000
- **Preços dos Itens**: 50 - 400 ouro
- **Recompensa de Combate**: 50 - 200 ouro
- **Penalidade por Derrota**: 100 ouro
